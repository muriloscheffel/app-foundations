# WellMeet 🍎
---
## Connecting Wellness & Sports through Community  
WellMeet é uma plataforma mobile (iOS) desenvolvida para conectar pessoas a eventos e espaços de bem-estar e esportes. O projeto nasceu dentro da Apple Developer Academy e utiliza a metodologia Challenge Based Learning para resolver a dificuldade de encontrar parceiros e locais adequados para práticas saudáveis.
